# SBD — Interactive Powerlifting Game

An interactive Python game combining two of my passions: computer science and competitive powerlifting.

## About the Project

SBD is a small, independently developed game that allows users to select between the three competitive powerlifting movements: squat, bench press, and deadlift.

The project explores interactive programming, animation, user input handling, and graphical interfaces using Python and Pygame.

## Features

- Three selectable powerlifting movements
- Custom animated lifting sequences
- User-defined weight selection
- Visual celebration effects

## Technologies

- Python
- Pygame

## Running the Game

1. Install Python.
2. Install Pygame using `pip install pygame`.
3. Run the main Python script.
